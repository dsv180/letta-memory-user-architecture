# Применение версии архитектуры памяти

Процедура применения лежит **внутри версии, рядом с самой архитектурой**:

→ **`1.4/memory-design/migration.md`**

Почему так: ядро памяти (`memory-design/`) самодостаточно. Вместе с архитектурой и
процедурами его можно перенести в любую память целиком — и сразу иметь всё нужное
для работы, без уроков и проектов. Этот файл оставлен только как указатель для тех,
кто пришёл на репозиторий и не знает, где искать.
