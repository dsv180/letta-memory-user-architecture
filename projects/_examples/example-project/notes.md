# Пример проекта

Демонстрационный проект. Его задача — показать, как выглядит минимальный
набор файлов проекта и что в каждом из них писать.

## Назначение файлов проекта
- `config.md` — техническая часть: пути, инструменты, git.
- `notes.md` — смысл проекта, специфика, контекст (этот файл).
- `tasks.md` — что делается и что в планах. Статус — только в `index.json`.
- `skills.md` — скиллы, релевантные проекту (создаётся, только если нужен).
- `glossary.md` — термины, специфичные для проекта (создаётся, только если нужен).
- `lessons.md` — уроки из ошибок, специфичные для проекта (только если нужны).

## Что писать в notes.md
- Смысл проекта: зачем он нужен.
- Подпроекты и их связи.
- Специфика, которую не видно из структуры папок.
- Контекст, который важно помнить при работе.
