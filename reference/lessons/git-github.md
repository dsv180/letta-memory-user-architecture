# Урок: облачный GitHub
## Клонирование репозитория
При запросе «склонируй репозиторий с GitHub» — сначала попробуй `git clone <url>` с таймаутом 120с+. Не предлагай SSH-ключи, токены, IP-адреса или другие обходные пути, пока простая команда не упала с конкретной ошибкой.
Если `git clone` не работает из-за прокси — попробуй `gh repo clone <owner>/<repo>` (GitHub CLI часто залогинен отдельно).
Не создавай репозиторий локально без явного разрешения — пользователь просит клонировать, а не создавать с нуля.
## Отдельный псевдоним для репозитория
Для репозитория, где все коммиты должны быть от агента, а не от реального пользователя — задать локальный конфиг:
    git config user.name "Китаец Вася"
    git config user.email "agent-local-8a9f04e0@example.com"
Это только локально, глобальные настройки не трогаются. Проверка:
    git config --local --get user.name
    git config --local --get user.email
