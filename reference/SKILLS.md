# Скиллы — справочник
Раздел вынесен из [[reference/PROJECTS.md]] (разгружает инструкции по проектам). Урок с опытом разведки и создания — [[lessons/project-skills.md]]; правило «урок → скилл» и команды — [[reference/core-rules.md]].

## Что пишется в `project/<name>/skills.md`
Файл содержит две независимые части:
- **Какие общие скиллы грузить в проекте.** Список имён; при желании — что не грузить. Это рекомендации, сами скиллы лежат в общих областях (`$MEMORY_DIR/skills/`, `~/.letta/skills/`, встроенные) и в MemFS не дублируются.
- **Какие скиллы здесь project-scoped.** Имя и пометка «project-scoped». Сам скилл лежит на диске проекта (см. ниже), в MemFS не кладётся.

Строка «project-scoped» всегда означает файл на диске проекта, а не копию в MemFS.

## Project-scoped скилл
Скилл, специфичный для одного проекта, лежит на диске по пути:
    <physical_path>\.agents\skills\<имя_скилла>\SKILL.md
Это файловая система проекта, не MemFS. В MemFS скилл не кладётся.

Когда поступает запрос «сделай скилл только для проекта»:
1. Создать папку `<physical_path>\.agents\skills\<имя_скилла>\`
2. Создать SKILL.md с frontmatter (name, description)
3. Убедиться, что CWD диалога = physical_path проекта
   (скилл подхватится при следующем ходу, придёт system-reminder)
4. В project/<name>/skills.md добавить строку с именем скилла
   и пометкой, что он project-scoped

Штатной команды для установки в .agents/skills/ у Letta нет.
Только ручное создание файла.

Ограничения:
- не версионируется в MemFS — только в git проекта, если он есть
- не переносится между машинами автоматически
- не виден другим агентам
- работает, только когда CWD диалога = папка проекта

## Области видимости скиллов и приоритет

| Приоритет | Область | Путь | Доступен |
|---|---|---|---|
| 1 | Project | `<physical_path>\.agents\skills\` | только когда CWD диалога = папка проекта |
| 2 | Agent | `$MEMORY_DIR/skills/` | всегда, в любом проекте |
| 3 | Computer | `~/.letta/skills/` | всегда, на этой машине |
| 4 | Bundled | внутри Letta Code | всегда |

При совпадении имён выигрывает высший приоритет: project перекрывает agent, agent — computer, computer — bundled.
Список доступных скиллов — команда `/skills`.
Скилл из памяти агента (`$MEMORY_DIR/skills/`) или из `~/.letta/skills/` доступен всегда — дублировать его в проект бессмысленно: придётся поддерживать две версии.
