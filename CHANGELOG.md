# История версий архитектуры памяти

Версия репозитория — это тег и Release; папок версий в рабочем дереве нет.
Записи — от новых к старым.

## v1.6 — 27.09.2026
- **Слой `lessons/` — верхним уровнем.** Уроки вынесены из `reference/`: граф ЛД делает группу из папки верхнего уровня, подпапка группой не становится.
- **Служебные файлы слоя проектов переехали в `reference/`.** `PROJECTS.md`, `index.md`, `index.json`, `_template.json`; в `project/` остаются только папки проектов.
- **Корневая папка проектов `projects/` → `project/`** — граф ЛД даёт отдельную рамку на проект только при корне `project`.
- **Ядро расширено `system/active-work.md`** — якорь «текущий проект и шаг»: новый диалог не наследует историю беседы и по CWD к проекту не привязан.
- **Проектное пространство (память ↔ диск).** Структура рабочей папки (файлы проекта в корне, `.temp/` вместо `input/`/`output/`), правила копий и бэкапов (`.bakN`), урок `project-work.md`, механика привязки диалога к проекту в `PROJECTS.md`.
- **`memory-design/repo.md` удалён** — ссылки переведены на проект.
- **Уроки де-фрагментированы:** `git-github` разнесён в `github-guide` и `git-local`, `mods` влит в `technical`.
- **Tooling под новую структуру:** `service_dir`, обновлённый `scan`, `new-project.py`, `selftest.py`.
- Версия во всех `description`: `1.5` → `1.6`.

## v1.5 — 25.09.2026
- Слепок перестроен на **плоскую структуру**: файлы версии лежат в корне репозитория, папка `1.4/` из корня убрана.
- Версионирование переведено на стандартные **теги и Releases GitHub** (`1.4` — последняя версия с папкой в корне).
- Проектная специфика сведена в одну папку `project-rules/` внутри проекта; отдельного проектного `lessons.md` больше нет. Общие уроки остаются в `reference/lessons/`.
- Добавлен `tools/bump-version.py` — подъём версии во всех `description` одной командой.
- Конвейер обезличивания переведён на корень репозитория: `scan`, `projects.dir`, `local_files`.

## v1.4 — 23.09.2026
- Уроки переработаны по темам: `reference/lessons.md` — индекс, `reference/lessons/` — отдельные файлы.
- Проекты описаны через `index.json` + `PROJECTS.md` + `_template.json`.
- Версия переехала в `description` frontmatter вместо отдельного поля `version`.
- Ядро `memory-design/` стало самодостаточным: устройство + процедуры + миграция; справочник репозитория ушёл из уроков.
- Обезличивание переведено на воспроизводимый конвейер `tools/`; история репозитория сброшена до одного коммита.

## v1.3, v1.2, v1.1
- Развивались на домашнем ПК; папки версий удалены, детали остались только в истории git.
