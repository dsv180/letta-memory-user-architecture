# Урок

## Суть
Одно-два предложения: чему научил случай.

## Применение
Когда правило срабатывает и на что ссылаться. Связанное правило — [[reference/core-rules.md]].

- Частный случай — буллетом.
- Второй частный случай — тоже буллетом.
