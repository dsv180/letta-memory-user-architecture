# Примеры файлов по слоям

Образцы формы, а не данные: показывают, что проверяет валидатор (`tools/validate_memory.py`) и как правило «Форма записи знания» ([[memory-design/architecture.md]]) выглядит в тексте.

Пара на каждый слой: `good/` — файл проходит проверку; `bad/` — те же места с типичными нарушениями. Сравнивать стоит по четырём точкам:

- **frontmatter:** есть `description`, лишних ключей нет, `version: 1.Х` — внутри `description`, а не отдельным ключом;
- **ссылки:** `[[path]]` — только полный путь от корня памяти;
- **форма:** нет даты вида `(дд.мм.гггг)` и атрибуций авторства («по команде …, 12.09.2026»), длинный файл разбит на разделы `## `;
- **стиль:** нумерация — только в шагах процедур, иначе буллеты.

Слои: `system/` — ядро; `reference/` — правила и справочники; `lessons/` — уроки; `project/` — проекты; `memory-design/` — устройство и процедуры.
