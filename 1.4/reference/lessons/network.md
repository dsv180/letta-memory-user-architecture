# Урок: сетевая безопасность

Назначение файла: правила сетевой диагностики и безопасности.

## Безопасность
- Сканировать порты и любую сетевую активность можно ТОЛЬКО на одном хосте,
  который явно указан в задаче. Полный запрет сканирования подсетей, диапазонов
  и нескольких хостов за один вызов. Нарушение — серьёзные последствия.

## Диагностика «нет интернета»
- Начинай с DNS: разрешается ли имя (`nslookup <домен>`).
- Проверь hosts-файл и прокси — прокси по-разному обрабатывает запросы браузера и CLI.
- Для CLI на Go (например, `gh`) нужен `ALL_PROXY`.
