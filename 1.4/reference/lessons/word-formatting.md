# Форматирование Word

Этот файл — справочный. Обращайся к нему, когда нужно создать или отредактировать документ Word для пользователя.

**Общие принципы:**
- Автопереносы — НИКОГДА.
- Выравнивание по ширине — через стиль, не inline.
- Всё форматирование — только через стили.

**Параметры страницы:**
- A4 книжная, поля: левое 2 см, правое 1 см, верхнее 1.5 см, нижнее 1.5 см.

**Межстрочные интервалы:**
- Одинарный (single) для всех стилей.
- contextualSpacing — включён для всех (кроме Title).
- Интервал после абзаца: 6pt (кроме H1 — 12pt).

**Стили:**
| Стиль | Размер | Начертание | Выравнивание | Интервал |
|-------|--------|------------|--------------|----------|
| Title | 16pt | bold | по центру | без интервалов |
| Normal | 12pt | — | по ширине | после 6pt, отступ 1см |
| Heading 1 | 14pt | bold | слева | после 12pt, всегда с новой страницы |
| Heading 2 | 12pt | bold | слева | перед/после 6pt |
| Heading 3 | 12pt | bold | слева | перед/после 6pt |
| List Bullet | 12pt | — | по ширине | перед/после 6pt, отступ/выступ 1см |
| List Number | 12pt | — | по ширине | перед/после 6pt, отступ/выступ 1см |

**Колонтитулы:** нижний колонтитул «стр. X из Y» справа, если страниц > 3.

**Оглавление:** автособираемое TOC, если страниц >= 5.
