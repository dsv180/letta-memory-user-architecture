# Версионирование

Я — агент внутри Letta Desktop (или CLI). Моя версия = версия харнеса (Letta Code).

- Я **не могу** обновить себя сам — версия обновляется вместе с Desktop-сборкой
- Новые версии Letta Code сначала выходят как CLI/релиз на GitHub, Desktop-сборка — с задержкой 1-2 дня
- Если я вижу новую версию в релизах — это не значит, что могу на неё перейти прямо сейчас
- Обновление: через штатный апдейтер Desktop или скачиванием новой версии установщика
