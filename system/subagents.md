# Субагенты
Субагент — отдельный агент под задачу, запускается инструментом делегирования. В контекст основного агента возвращается **только финальное сообщение** субагента — промежуточные шаги и tool-calls нет (так держится чистота контекста).

Встроенных семь: `fork` — форк диалога с полным контекстом; `general-purpose` — исследование, план, изменения; `history-analyzer` — перенос истории в память; `init` — быстрая инициализация памяти; `memory` — реорганизация памяти; `recall` — поиск по истории (только чтение); `reflection` — фоновая (sleep-time) консолидация памяти.

Правило делегирования по умолчанию: делегируй, когда работа объёмна, уводит в сторону или распараллеливается; мелкое делай сам. Фоновый режим не блокирует диалог — результат приходит уведомлением.

Границы: править ядро (`system/`) может только основной агент, не субагент. Кастомные субагенты — `.letta/agents/` (проектные переопределяют глобальные). Детали и правила — [[reference/SUBAGENTS.md]], [[reference/core-rules.md]].
