# Урок: технические специфические случаи
- npm не заблокирован в корпоративной сети — проблема может быть в имени пакета, версии или платформенном суффиксе. (Пример: `@example.ai/xls-cli` vs `@example.ai/xls-cli-win32-x64`).
- GitHub в России не заблокирован — проблема может быть в корпоративном прокси, который по-разному обрабатывает запросы браузера и CLI.
- Gh CLI (Go-based) требует `ALL_PROXY`, а не `http_proxy`/`https_proxy`.
- agent-folders.json не управляет CWD при переключении на агента — не пытайся использовать этот файл для смены рабочей папки.
- Иконки агентов менять можно — не утверждай обратное.
- Время — всегда бери из system-reminders, не гадай. Часовой пояс пользователя — домашний регион, GMT+3.
- При установке любого ПО сначала уточняй режим: от имени администратора для всех пользователей или только для текущего. На Windows это критично — влияет на PATH и совместимость.

## Моды и инструменты
- english-guard мод — не блокируй русский язык. Модифицируй детектор, чтобы пропускать кириллицу.
- Моды должны быть самодостаточными: описание, глоссарий — в MemFS, не ссылайся на файлы в Downloads.
- Для работы с Office-файлами используй OfficeCLI и xls-cli. Python-библиотеки (openpyxl, python-docx) — больше не использовать.
- Хелперы скиллов кладут кэш в первый доступный временный каталог (`TMPDIR`, `TEMP`, `TMP`, `/tmp`) — у нас это системный `<temp dir>`, а не проектный. При работе в проекте путь надо переопределять флагом: у встроенного скилла `letta-guide` — `--cache-dir <physical_path>\.temp\letta-docs-cache`. Скилл встроенный (лежит в дистрибутиве Letta Code), править его не нужно — только передавать флаг.
- Хелпер `letta-guide` отдаёт один и тот же путь файла кэша при разных `--docs-url`: страницу читай сразу после выгрузки или сразу копируй файл кэша под осмысленным именем, иначе следующая выгрузка затрёт предыдущую.
- **Любой вопрос про работу Letta** (команда, флаг, настройка, поведение) — сначала разобрать сам вопрос: что именно спрашивают и в каком слое ответ, и только потом открывать скилл документации `letta-guide` и тянуть нужную страницу. Не грепать индекс по имени команды и не лезть в код, не поняв, что спрашивают (разбор вопроса про `/compact`).
