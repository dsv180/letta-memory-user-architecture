# Windows-гайд

Этот файл — справочный. Не читай его автоматически. Обращайся к нему, когда готовишь команды или скрипты для Windows. Применяй эти правила обязательно.

## Основные правила для команд и скриптов

**Интерпретатор Python** — команда `python` разворачивается в Python 3.12.10 (`~\AppData\Local\Programs\Python\Python312\python.exe`). Рядом установлен и Python 3.14 (`Python314`, он же по умолчанию у лаунчера `py -0p`), но в PATH первым идёт `python` = 3.12. `python3` не используй — его нет.

**Оболочка** — Bash tool в Letta на Windows исполняет команды в PowerShell. Скрипты пиши для PowerShell (`.ps1`) или CMD (`.bat`/`.cmd`). Bash-синтаксис (`&&`, `||`, `;`, heredocs) не используй — не работает.

**Кавычки и пробелы**:
- В PowerShell: двойные кавычки (`"..."`) подставляют переменные, одинарные (`'...'`) — нет.
- В CMD: только двойные кавычки.
- Пути с пробелами всегда заключай в двойные кавычки.
- **Бэктик внутри двойных кавычек — escape-символ**: он съедает следующий за ним символ. Поэтому markdown-спан в аргументе CLI окружай **двойным** бэктиком (пиши `` ``code`` ``, а не `` `code` ``) — в PowerShell это и даёт рабочий спан. Символ `$` в двойных кавычках раскрывается как переменная — экранируй бэктиком или не используй. Пример: `gh issue close <N> --comment "..."`.

**Переменные окружения**:
- Читать: `$env:VAR`.
- Устанавливать: `$env:VAR="val"`.
- `export` не работает. Используй `$env:`.

**POSIX-утилиты НЕ РАБОТАЮТ**: `head`, `tail`, `grep`, `cut`, `sort`, `uniq`, `wc`, `sed`, `awk`, `cat`, `touch`, `chmod`, `diff`, `tee`.

**Обязательные замены**:
| Вместо POSIX | Используй PowerShell |
|--------------|----------------------|
| `head -n N` | `Select-Object -First N` |
| `tail -n N` | `Select-Object -Last N` |
| `grep pattern` | `Select-String "pattern"` |
| `head -n N file` | `Get-Content -Path file -TotalCount N` |
| `tail -n N file` | `Get-Content -Path file -Tail N` |
| сортировка | `Sort-Object` |
| уникальные | `Get-Unique` |
| подсчёт строк | `Measure-Object -Line` |
| вывод в файл | `Out-File -Encoding utf8 путь` |

Для сложной обработки пиши Python-скрипт и запускай через `python`.

**Проверка перед выполнением**:
Перед запуском команды, которая изменяет файлы или систему, сначала проверь память (Grep/Glob/Read по `$MEMORY_DIR`), не было ли такой команды раньше. Если команда требует прав администратора — используй `Start-Process -Verb RunAs`.

**Обработка ошибок**:
После выполнения команды проверяй код возврата: `$LASTEXITCODE` в PowerShell, `%ERRORLEVEL%` в CMD. Если команда упала — прочитай вывод, пойми причину, исправь и повтори. Не игнорируй ошибки.

**Copy-Item: источник-папка вкладывается внутрь приёмника**

`Copy-Item -Recurse -Force "$src\folder" -Destination "$dst\folder"`
→ создаёт `$dst\folder\folder\` — источник вкладывается подпапкой

`Copy-Item -Recurse -Force "$src\folder\*" -Destination "$dst\folder"`
→ перезаписывает файлы на месте, без вложения

Правило: для синхронизации папки в существующий приёмник — всегда добавлять `\*` к источнику.

**robocopy: коды возврата**
`robocopy <src> <dst> /E` копирует содержимое целиком (включая скрытые файлы `.git`). Коды возврата: **0–7 — успех** (1 = файлы скопированы, 2 = лишние в приёмнике, 3 = 1+2 и т.д.), **≥8 — ошибка**. Поэтому exit 1 — не сбой; проверяй `$LASTEXITCODE -ge 8`.
Перед бэкапом в фиксированный путь сначала проверь, нет ли там уже копии: затирать старый бэкап вслепую нельзя — делай новый с датой в имени.

## Домашняя директория агента (CWD)
- «Домашняя директория» для агента — это **Current Working Directory** (CWD), установленная в сессии.
- Сейчас это `<CWD агента>`.
- НЕ путай с домашней директорией пользователя Windows (`C:\Users\<username>\`) — она пользовательская, агенту до неё нет дела.
- Если пользователь говорит «твоя домашняя директория» — имеется в виду CWD агента.

## Кодировка
- CMD выводит русский текст в CP866 — это кракозябры в UTF-8.
- PowerShell — UTF-8.
- Кириллица в аргументах `gh` из PowerShell доходит корректно — проверено на комментариях к issues (`--body`/`--comment`), обходные пути не нужны. Ломается только `--commit-callback` у Python, там нужен отдельный скрипт ([[lessons/git-local.md]]).
- Если видишь кракозябры — сохраняй вывод в файл: `Out-File -Encoding utf8`.
- Переносы строк: рабочая копия файлов памяти на Windows бывает CRLF (git `autocrlf`), в индексе — LF. Многострочный `old_string` в `memory()` по CRLF-файлу не матчится; как править структурно — [[lessons/memory.md]].

## Пути и файлы пользователя
- Загрузки всегда в `~\Downloads\`. Если нужно найти скачанный файл — ищи там.
- Если нужно сохранить файл — сначала скопируй из Downloads, потом сохраняй куда нужно.

## Регистр в OpenSSH
Перед созданием `.ssh` выполни `echo %USERNAME%` на целевой машине и создавай папку в точном регистре.
